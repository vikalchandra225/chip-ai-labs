# CHIP AI LABS

Static website for chipailabs.in.

## Deploy on GitHub Pages
1. Upload all files in this folder to the `chip-ai-labs` repository.
2. Go to Settings → Pages.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. Add `chipailabs.in` under Custom domain.
6. At your domain registrar, add the DNS records GitHub provides.

No paid hosting is required.
